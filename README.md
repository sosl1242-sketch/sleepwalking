# sleepwalking

의사와 환자의 몽유병을 중심으로 한 심리 서사 프로젝트입니다.

이 저장소는 완성 원고를 바로 쓰기보다, 이야기의 방향과 분위기, 인물 관계, 장면의 기능을 먼저 잡아두기 위한 작업 공간입니다. 핵심 목표는 독자가 설명을 따라가는 것이 아니라 장면을 통과하면서 점점 불안과 이입을 느끼고, 결말 이후에도 잔상이 남도록 만드는 것입니다.

## 현재 문서 구성

- `기획.md`  
  작품의 로그라인, 장르, 독자 경험, 이야기의 약속과 피해야 할 방향을 정리합니다.

- `주제와 메시지.md`  
  작품이 전하고자 하는 질문과 여운, 반복해서 붙잡아야 할 정서적 중심을 정리합니다.

- `설정.md`  
  의사, 환자, 병원, 몽유병 소재, 반복 이미지, 관계의 긴장 등을 정리합니다.

- `플롯 구조.md`  
  전체 흐름을 4부 구조와 장별 흐름으로 나누어 정리합니다.

- `장면 목록.md`  
  각 장면이 해야 할 역할, 감정, 단서, 다음 장면으로 이어지는 질문을 정리합니다.

- `소설 초안.md`  
  실제 문장으로 작성한 도입부 중심의 작업용 초안입니다. 완성본이 아니라 방향을 잡기 위한 제0고입니다.

- `문체 가이드.md`  
  이 작품에서 유지할 문장 리듬, 분위기, 묘사 방식, 금지할 표현 습관을 정리합니다.

- `리서치 TODO.md`  
  몽유병, 수면 검사, 병원 윤리, 진료 기록 등 나중에 확인하면 좋은 조사 항목을 정리합니다.

- `작업 체크리스트.md`  
  장면을 고치거나 새로 쓸 때 확인할 항목을 정리합니다.

## 작업 원칙

1. 이야기는 의사와 환자의 몽유병을 중심축으로 유지합니다.
2. 몽유병을 단순한 공포 장치로 쓰지 않고, 인물의 내면과 관계의 균열을 드러내는 장치로 다룹니다.
3. 결말은 설명보다 잔상으로 남기는 방향을 지향합니다.
4. 새로운 반전이나 세계관보다 인물의 관찰, 기록, 침묵, 반복되는 행동을 중심에 둡니다.
5. 하네스 프롬프트와 GPT 답변 제한 규칙은 아직 추가하지 않았습니다. 이후 별도 요청 시 추가할 예정입니다.

## 임시 작업 제목 후보

- 몽유의 방
- 닫히지 않는 문
- 잠든 사람의 진술
- 복도의 끝에서
- 깨우지 말아야 할 사람
